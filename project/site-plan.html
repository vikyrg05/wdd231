Site Plan

Site Name

Cochabamba Travel Guide

This name was chosen because it represents a website about tourism in Cochabamba.

Site Purpose

This website will serve as a guide to tourist attractions in Cochabamba, Bolivia. It will provide detailed information about different places, including descriptions, images, and categories. The site will also allow users to explore multiple locations, view recommendations, and interact with the content through dynamic features such as filtering and detailed views.

Scenarios

  • What are the most popular tourist places to visit in Cochabamba?
  • What are the best times and recommendations for visiting these places?

Color Scheme

  • Green: Used for headings and accents to represent nature and tourism.
  • Blue: Used for navigation and links to create a calm and trustworthy feeling.
  • White: Used as the background color to keep the design clean and simple.

Typography

The website will use Roboto as the main font. Roboto will be used for headings and body text because it is simple and easy to read. A sans-serif font will be used as a backup font for all text.
